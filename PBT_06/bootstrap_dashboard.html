Câu hỏi thường gặp

Để quản lý đơn hàng hiệu quả, bạn nên: (1) Sử dụng bộ lọc để tìm đơn hàng theo trạng thái hoặc ngày; (2) Cập nhật trạng thái đơn hàng định kỳ; (3) Theo dõi chi tiết giao hàng; (4) Phản hồi khách hàng kịp thời.

Để tích hợp phương thức thanh toán mới, vào phần "Cài đặt" → "Phương thức thanh toán" → "Thêm mới" → Điền thông tin nhà cung cấp thanh toán → Kích hoạt.

Truy cập "Báo cáo" → Chọn loại báo cáo (Doanh thu, Sản phẩm bán chạy, Khách hàng...) → Chọn khoảng thời gian → Nhấn "Xuất" để tải file Excel hoặc PDF.

Nhấn vào avatar người dùng (góc trên phải) → Chọn "Hồ sơ" → "Đổi mật khẩu" → Nhập mật khẩu cũ và mật khẩu mới → Lưu thay đổi.
